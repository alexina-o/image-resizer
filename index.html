How to Use

  1. Queue Your Images: Drag and drop your files into either the Packshot / Swatch or Lifestyle drop zone depending on the required preset. You can queue images into both boxes before processing.
  2. Naming Single Products: If processing images for a single product, enter a Custom File Prefix (e.g., SKU_1234) and keep Sequential Numbering checked. Packshots will be numbered first (_01, _02), followed directly by Lifestyle images.
  3. Naming Multiple Products: If processing a batch containing multiple different products (e.g., a foundation line with multiple color variants), leave the prefix blank and uncheck sequential numbering to retain original filenames.
  4. Export: Click Process All & Download ZIP to resize, align, and download your complete batch in a single zip archive.
